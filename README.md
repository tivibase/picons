# 📡 Picons TVBase

Este repositorio contiene **picons** (iconos de canales de televisión) listos para usar en sistemas de IPTV, decodificadores y software de gestión de listas de canales.

Los picons permiten identificar visualmente los canales en guías de programas (EPG), listas M3U y entornos de usuario, mejorando la experiencia al navegar entre canales.

---

## 🎯 Contenido del repositorio

Aquí encontrarás picons organizados por proveedor y tipo de servicio:

- 📺 **Movistar+** – Canales nacionales y temáticos.
- 🌐 **Pluto TV** – Canales FAST gratuitos en streaming.
- 🛰️ **TDT** – Televisión Digital Terrestre de España.
- 📡 **Otros proveedores** – En proceso de incorporación.

Cada conjunto de picons está optimizado para una visualización clara en diferentes resoluciones.

---

## 🖼️ Especificaciones de los picons

- 📐 **Resolución:** 320 x 180 píxeles  
- 🎨 **Color:** blanco  
- 🪟 **Fondo:** transparente (formato PNG recomendado)  

Estas especificaciones garantizan uniformidad y compatibilidad en distintos dispositivos y aplicaciones de IPTV.
